# Town of Victoria Park ACROD parking source

The **Transport** section of the Town’s public map includes an **Acrod Bays** point layer. [parking.geojson](parking.geojson) contains all 93 points returned on 27 November 2026, including 41 within the ABS East Victoria Park suburb boundary. [Town online maps](https://www.victoriapark.wa.gov.au/about/town/places-and-maps/online-maps.aspx) · [ABS suburb reference](https://www.abs.gov.au/census/find-census-data/quickstats/2021/SAL50468)

- **Source** [Acrod Bays GeoJSON service](https://maps.vicpark.wa.gov.au/pozi/qgisserver?MAP=E%3A%2FPoziProjects%2FTransport.qgs&SERVICE=WFS&VERSION=1.1.0&REQUEST=GetFeature&TYPENAME=Acrod_Bays&SRSNAME=EPSG%3A4326&OUTPUTFORMAT=GeoJSON)
- **Attribution and reuse** Town of Victoria Park. The contributor confirmed permission to redistribute the layer in this repository. No general reuse licence is recorded here. [Town copyright statement](https://www.victoriapark.wa.gov.au/copyright-statement.aspx)

Each feature preserves the council’s coordinates, source ID, bay type and location label. Bays at the same address retain separate points. The count describes the source snapshot. [GeoJSON contribution guide](../README.md)

Points within the ABS East Victoria Park boundary carry the suburb label for search. [ABS Suburbs and Localities, CC BY 4.0](https://geo.abs.gov.au/arcgis/rest/services/ASGS2021/SAL/MapServer)
